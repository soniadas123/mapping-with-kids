# Mapping with Kids

Hands-on courses and activities in maps, satellites and code for children in
Bengaluru, taught by Geospatial Specialist
[Sonia Das](https://soniadas123.github.io/soniadas/).

Children learn the way people who make maps for a living work. They use real
data about places they know, make maps that answer questions, and finish with
something they built themselves.
